# 自己做的游戏终于上了 Steam 新品节，激动，也有点忐忑

大家好，我是《小狗来啦》的独立开发者。

我一个人做的桌宠游戏，终于参加 Steam 新品节了。

真到了这一天，心情有点复杂。激动是真的，忐忑也是真的。

终于有机会让更多人看到自己的作品了。但大家会不会愿意点进来，试玩之后会不会喜欢，心里又没有底。

所以，还是先把小狗带来，和大家见个面。

《小狗来啦》是一款桌面宠物游戏。小狗会待在电脑桌面一角，陪你工作、学习，或者玩其他游戏。

你打字、点击鼠标时，它也会做出反应。平时可以收集装扮，给它换换帽子、戴戴眼镜。休息时，也能切到牌桌玩几手轻量扑克。

我希望它能成为那种，你忙自己的事情时，愿意留在桌面上的小伙伴。

这次新品节，试玩版已经可以免费下载了。

我也准备了一份神秘的见面礼：**完成试玩版里的庆典收集，就能领取「2026 庆典纪念款」装扮。**

具体是什么，先留个悬念，等大家自己揭晓。

这份 2026 纪念款预计不会继续发放到 2027 年。以后即使再有新的庆典装扮，也会是另一份纪念。

考虑到新品节有很多游戏值得体验，这次也特意加快了试玩节奏。

**盲盒倒计时结束就能开，不消耗筹码。**

希望大家轻松认识小狗、收下一份纪念，也有时间去试试其他好游戏。

做游戏的时候，很多事情可以自己钻研。但做出来的小狗能不能让人喜欢，还是得交给大家来回答。

如果你愿意下载试玩，我很期待听听你的感受。喜欢哪里、哪里不好用，都欢迎在评论区告诉我。

如果这只小狗刚好合你的眼缘，也欢迎给《小狗来啦》加个愿望单。

希望这次新品节，能让它遇见更多愿意把它留在桌面上的人。

生活忙忙碌碌，小狗缝缝补补。
