[b][置顶] BUG 反馈说明与模板[/b]

欢迎来到《小狗来啦》的 Steam 社区！

如果你在游戏中遇到了 BUG、异常行为或其他明显不符合预期的情况，请[b]单独新建一个讨论主题[/b]，不要直接回复在这篇置顶帖下面。

每个问题单独开帖，可以方便其他玩家搜索自己是否遇到了相同问题，也方便我们针对每一个 BUG 分别进行排查和后续沟通。

[b]提交前可以先看一下[/b]

如果社区里已经有人反馈过相同的问题，可以直接回复在已有帖子下面，并补充你遇到的情况。

如果没有找到相同的问题，再新建一个主题，并尽量参考下面的格式填写。

[b]BUG 反馈模板[/b]

[code]
标题：
请用一句话简单描述问题

发生了什么：
描述你实际遇到的情况

你原本预期会发生什么：
描述正常情况下你认为应该出现的结果

如何复现：
1.
2.
3.

是否可以重复出现：
每次都会 / 偶尔出现 / 目前只遇到过一次

截图或视频：
如果方便的话可以提供

其他补充：
任何你认为可能有帮助的信息
[/code]

如果有些信息不清楚，也不需要为了填满模板而勉强填写。

哪怕只是简单说明“发生了什么”，也可能对我们很有帮助。

[b]关于诊断日志[/b]

普通 BUG 不需要主动导出诊断日志。

如果某个问题需要进一步排查，我们可能会在你的帖子里请你使用游戏内的[b]导出诊断日志[/b]功能，并提供导出的 ZIP 文件。

到时候我们会单独告诉你该如何发送。

[b]游戏建议与体验反馈[/b]

如果你想反馈的不是 BUG，而是：

[list]
[*]希望增加的新功能
[*]玩法建议
[*]装扮或收集体验
[*]数值和平衡
[*]UI 与操作
[*]某个地方虽然没有出错，但感觉奇怪、麻烦、容易困惑
[/list]

都可以直接新建普通讨论主题，不需要使用这份 BUG 模板。

你可以使用自己习惯的语言发帖。

感谢每一位愿意帮助小狗成长的玩家！
