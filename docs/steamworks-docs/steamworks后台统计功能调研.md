| 页面路径 | Steamworks 字段 | 中文含义 | 能回答什么 |
|---|---|---|---|
| `Sales & Activations Reports → Players → Lucky Dog Rise Playtest` | `Daily Active Users` | 日活跃用户数，**DAU** | 每天有多少不同玩家实际活跃 |
| 同上 | `Peak Concurrent Users` | 峰值同时在线用户数，**Peak CCU** | 当天最高同时在线人数 |
| 同上 | `.csv` | CSV 导出 | 可导出逐日 DAU 和 Peak CCU |
| Playtest 总览页 | `Current Players` | 当前在线玩家数 | 此刻有多少玩家在线 |
| Playtest 总览页 | `Lifetime Unique Users` | 历史累计独立用户数 | 一共有多少不同 Steam 账号实际运行过游戏 |
| Playtest 总览页 | `Daily Active Users` | 日活跃用户数，**DAU** | 首页直接给过去 7 天平均 DAU |
| Playtest 总览页 | `Lifetime Retail Units` | 历史累计零售激活数 | 通过 Steam Key 等方式激活的数量 |
| Playtest 总览页 | `Lifetime Free Licenses` | 历史累计免费授权数 | Playtest 免费授权数量 |
| Playtest 总览页 | `Lifetime Total Units` | 历史累计总授权数 | 所有授权方式的合计 |
| `Playtest 总览页 → Playtime stats` | `Lifetime Users Measured` | 纳入游玩时长统计的历史用户数 | Steam 实际用于时长分析的样本数 |
| 同上 | `Average Time Played` | 平均游玩时长 | 玩家总体平均玩多久 |
| 同上 | `Median Time Played` | 游玩时长中位数 | 典型玩家大约玩多久 |
| 同上 | `Minimum Time Played / Percentage of Users` | 达到最低游玩时长的玩家比例 | ≥10 分钟、≥30 分钟、≥1 小时等比例 |
| 同上 | `Users Bucketed by Time Played` | 按游玩时长分桶的玩家数 | 玩家时长分布直方图 |
| `Playtest 总览页 → Downloads by Region` | `Total Downloads` | 下载用户数 | 某时间段内符合 Steam 下载统计口径的用户数 |
| 同上 | `Region / Country` | 地区 / 国家 | 下载玩家的国家和地区分布 |
| `Regional key activations report` | `Retail key activations` | Steam Key 零售激活数 | 某天有哪些国家的玩家使用 Key 激活 |
| `Regional sales report` | `Regions and Countries` | 地区与国家统计 | Key 激活/Units 等发行侧地域分布 |
