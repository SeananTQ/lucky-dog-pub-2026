## 可直接替换的图标

2026-11-23 核对：公开界面的 `TabIcon_Room.svg`、`Icon_RoomGame.svg`、`Icon_RoomGameWork.svg` 已有独立图形，不再列为模板副本。内部扑克的胜者、等待、托管三个图标仍与 `Icon_Template.svg` 一致。文件相互独立，替换状态不自动代表所有显示场景已完成人工验收。

以下六个文件均位于 `lucky-dog-rise/Assets/UI/Icon/`，当前 `viewBox` 都是 `0 0 64 64`。下列显示大小是场景的布局单位，会再随 UI／小狗／扑克视口倍率变化，不是所有设备上固定的物理像素。

### 公开联机界面

- **[TabIcon_Room.svg](../../lucky-dog-rise/Assets/UI/Icon/TabIcon_Room.svg)：系统面板的「联机」页签。**
  - 图标最大宽度为 32，按钮基准尺寸为 56×44；沿用其他页签的单色图标表现。
  - 选中／未选中状态分别使用 `PanelTopTabSelected`／`PanelTopTab`，选中时 Theme 会对图标调色。设计稿需兼顾两种底色。
  - 它与装扮分类的 `TabIcon_Dog.svg` 是不同文件；后者本来就以爪印表示小狗，不因形状与模板相同而列为待替换项。

- **[Icon_RoomGame.svg](../../lucky-dog-rise/Assets/UI/Icon/Icon_RoomGame.svg)：默认玩法图标。**

  - 当前「一起聊天」和捣乱德州共用这个文件；`GameIcon()` 只有「各自工作」另取专属图标，其余玩法使用本图。
  - 若主人需要为捣乱德州画专属扑克图标，应另约定资源名并由程序接入映射；直接把本文件改成扑克图案，也会改变「一起聊天」的图标。本轮不改映射或新增玩法资源。

- **[Icon_RoomGameWork.svg](../../lucky-dog-rise/Assets/UI/Icon/Icon_RoomGameWork.svg)：「各自工作」玩法图标。**
  - 同样用于房间列表和「当前玩法」一行，基准显示区域为 26×26。

## 已有独立图形，可按需优化

- 成员列表显示区域 22×22，小狗姓名栏 18×18；图标独立显隐，房主变化时同步更新，不拼入玩家姓名。姓名栏为图标与间距预留宽度。
- 保留主人原图及颜色，显示范围已裁为 64×64。当前使用 `viewBox="5879 3440 64 64"` 对应原图坐标；不能只把原点改回 `0 0` 而不平移图形。后续可正常导出原点为零的新稿并保持相同视觉留白。
- 房主图标与 `Icon_PokerWinner.svg` 的本局胜者标记是两种含义，替换互不影响。

**[Icon_RoomChat.svg](../../lucky-dog-rise/Assets/UI/Icon/Icon_RoomChat.svg)** 为三个圆点的对话气泡，两个入口共用资源：

- 小狗头顶聊天入口：42×42 透明点击区域，图标最大宽度 34；使用独立 `ChatEntryButton`，没有圆形底板，保留悬停变亮和按下反馈。图标中心及边界夹紧随按钮实际尺寸计算；发送、取消仍使用原 `ChatButton`。
- 扑克顶部快捷栏聊天入口：图标最大宽度 40，继续使用快捷栏按钮样式。修改 SVG 颜色会同步影响此处，不等于快捷栏的按钮外观也已修改。
- SVG 的气泡填充为奶油白 `#F6F3E8`，圆点及细描边为暖深棕 `#65483E`，`viewBox` 为 `0 0 64 64`。入口 Theme 仍会按交互状态调制亮度；设计时兼顾深浅桌面背景。

上述房主与聊天图标由 `f93699f` 提交，主人于 2026-11-23 确认本轮视觉效果可用；以后调整仍需检查实际缩放与两个聊天入口。

## 不属于独立 SVG 的部分

以下外观不能通过覆盖上述图标文件完成更换；主人计划调整时，需同时协调对应场景或 Theme。

- **庄家标记**：牌手面板及飞行交接效果使用圆形底板加字母 `D`，样式为 `DefaultTheme.tres` 的 `RoomPokerDealer`，没有独立庄家 SVG。
- **牌手底板、行动状态与伸缩状态条**：使用 `DefaultTheme.tres` 中的 `RoomPokerPlate`、`RoomPokerActive`、`RoomPokerWinner`、`RoomPokerWinnerFocus`、`RoomPokerResultDrawer`、`RoomPokerRank` 和 `RoomPokerClock`。换皇冠不会自动更换这些底色、文字色或进度条。
- **聊天气泡**：主体样式位于 [RoomChatTheme.tres](../../lucky-dog-rise/Scenes/Rooms/RoomChatTheme.tres)，尾巴是场景中的 `Polygon2D`；若改底色，尾巴颜色也要配套。它与聊天入口图标是两部分。
- **其他小狗姓名栏**：底板是 [RoomNameBar.tscn](../../lucky-dog-rise/Scenes/Rooms/RoomNameBar.tscn) 内的 `StyleBoxFlat`，不是贴图，也没有完全跟随主 Theme 换色。
- **扑克恢复对话框**：复用主 Theme 的扑克欢迎提示视觉样式。调整共用样式也会影响欢迎提示，不能把它当作仅作用于断线提示的独立美术资源。

## 替换与并行开发约定

- 只更换图形时保留对应文件名、目录和 64×64 显示范围（房主图标的坐标原点例外见上文）；不要改 `Icon_Template.svg` 来期待所有副本一起更新，也不要手动改生成的导入缓存。
- 图形居中并保留必要透明留白。SVG 画布不变不代表视觉占用不变，阴影、描边和尖角仍需在实际小尺寸下检查。图标不内嵌语言文字。
- 路径或文件格式变化、调整面板大小、改变状态标记位置，以及替换原来的文字／Theme 图形，交给程序同步修改引用和布局。
- 主人修改美术时，Codex 可以继续开发其他功能。若双方需要同一个 SVG、Theme 或场景，先协调文件范围；Codex 提交时只提交其负责且已完成的改动，不顺带提交主人尚未完成的美术。
- 美术完成后由 Godot 正常重新导入，检查页签两种状态、房间两种玩法图标、聊天两个入口，以及皇冠／庄家／托管同时出现时的遮挡。程序逻辑检查可以先做，最终显示和包内验收在正式素材就位后进行。
