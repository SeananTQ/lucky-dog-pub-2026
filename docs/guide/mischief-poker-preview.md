# 捣乱德州第二阶段：主场景本机试玩

玩法规则见[捣乱德州玩法设计](../game-design/捣乱德州玩法设计.md)，纯规则核心见[第一阶段说明](mischief-poker-core.md)。本文记录界面接入、开发测试入口及验收边界，不决定正式多人开局、准备或经济规则。

## 试玩入口

1. 从开发启动器选择“Steam 模拟环境”。
2. 打开“联机”页，加入默认模拟房间，或加入有陪伴小狗的陪伴房间。
3. 成员列表下点击“捣乱德州 · 本机试玩”。房间至少需要两名成员，本地准备阶段和房间请求进行期间不能开始。

该入口只在显式 Mock 环境提供。真实 Steam 房间不显示该入口，也不会向其他玩家发送测试牌局。按钮在正式 Release 中隐藏；调试驱动仅在 `DEBUG && !DEMO_BUILD && !RECORDING_BUILD` 下编译。

已经下注、尚未结束的单人牌局需要先完成并领取奖励。不能用试玩入口清空单人手牌或绕过结算。试玩进行中再次点击入口返回同一场试玩，不重新收取底注。

## 当前交互

- 复用实际扑克主场景、现有牌桌、手臂、卡牌素材及全屏／半屏联机宿主。
- 座位按进入试玩时的固定名单分配，与小狗摆放位置无关；首局庄家为当前房主。试玩期间的成员、成员身份、房主、房间或房间玩法发生变化时，结束本机试玩并清理界面。真实网络重连与换主恢复留给后续阶段。
- 自己的两张暗牌显示在手臂附近。其他小狗右侧显示两张牌背、座位编号、筹码和庄家／当前回合标记；结算时才展示其手牌正面。
- 公共牌区显示五张明牌。当前玩家最多点击两次，可连续点击同一槽位恢复原牌；点击手臂结束剩余操作。整回合 15 秒，第一次操作不延长期限。
- 所有其他成员由本机测试驱动自动操作。随机模式只做简单合法翻牌或结束操作，用于界面验收，不是正式扑克机器人策略。
- 所有人结束后，短暂保留最后一次翻牌反馈，再统一补牌、亮牌及结算。结算结果包含各座位的牌型与所得筹码，显示下一局庄家及是否逆序；列表可滚动，操作按钮固定在列表外。
- 下一局由测试按钮明确触发。初始每人 1000 筹码，每局底注 100，余额沿用；有人不足底注时不扣款、不自动补款，提示结束并重新开始试玩。
- 试玩筹码和系统收走的平分余数只在内存牌局中计算，不读写单人筹码、Steam Stats 或存档。退出试玩恢复单人筹码、赔率栏、下注筹码和操作引导入口。
- 试玩期间暂停单人欢迎提示、便签和自动操作提示，不替玩家完成这些引导。顶部仍保留牌型帮助、聊天及回桌宠入口，暂时隐藏不适用的单人操作引导。打开模态界面或聊天输入时不能操作公共牌；牌局计时仍继续，需停表时使用测试暂停。
- 返回桌宠不会退出试玩；回来后恢复同一手牌和余额。其他小狗沿用现有自由拖拽、画布层级及位置交接；其卡牌区域计入边缘约束和拖动命中范围。

## 开发控制

侧栏提供：

- 暂停／继续：冻结／恢复本机牌局时钟和自动操作，暂停时仍可手动翻牌、结束回合或单步操作。
- 机器人一步：让当前其他玩家做一次合法操作，或在待补牌阶段执行结算；不能替本机玩家操作。
- 当前超时：把时间推进到当前玩家的回合期限，通过正常超时逻辑结束该回合。
- 下一局牌堆预设：随机牌、公共牌平局、庄家获胜、其他人获胜。预设从下一局生效；非随机预设中其他小狗自动结束操作，便于观察指定结算。玩家若主动更改公共牌，预设的胜负可能随之改变。
- 结束试玩：清理当前内存牌局并恢复单人显示，不退出联机房间。

中文为当前试玩文案，英文为临时回退文案；英文玩法正式名称及其他语言不在本阶段定案。

## 程序边界

- `MischiefPokerPreviewSession` 仅是开发环境的内存权威适配器：复用第一阶段规则，不复制发牌、判型、超时或轮庄算法。其预设牌堆不能成为未来客户端可调用的网络命令。
- `ModeManager.MischiefPreview` 负责入口、房间身份校验、生命周期和主场景接线。正式 Steam 传输尚未接入。
- `RoomPokerTableView` 只消费本机 `PokerPlayerView`；其他小狗的展示只从公开视图的结算结果取牌面。未结算时不向远端卡牌控件提供真实暗牌。
- `RoomPokerCardView` 使用快照驱动可取消的翻面 Tween；不使用脱离节点生命周期的延迟计时器。换局、取消和退出后旧翻牌不能覆盖新快照。
- 界面结构保存在 `Scenes/Rooms/Poker/`，字体样式在 `DefaultTheme.tres`。新增 Godot 节点类纳入混淆保留列表；Demo／录屏沿用 `Scenes/Rooms/*` 与 `Scripts/Rooms/*` 的排除规则。

## 自动验证入口

- `dotnet run --project tests/MischiefPoker/MischiefPoker.csproj -c Release`：原规则核心检查加本机驱动检查，覆盖 2～6 座位、预设、暂停、自动机器人、超时、守恒和强制轮庄。测试失败会写出日志并返回非零退出码，避免未捕获 CLR 异常触发 Windows 错误对话框。
- 主场景参数 `-- --rooms-mischief-main-smoke`：在内存 Steam Mock 中验证真实 UI，覆盖全屏三人、半屏六人、中英文、暗牌隐私、重复翻牌、非当前回合拒绝、手臂结束、平局、下一局、超时、筹码隔离、桌宠往返、离房清理及单人手牌保护。截图输出至 `.local-build/mischief-poker/`。
- 既有 `--rooms-poker-main-smoke` 用于检查正常单人扑克和联机狗狗的拖拽、层级、聊天及位置交接没有回归。

上述检查不代表真实 Steam 双机、正式玩家参与流程、网络断联恢复、多人资金系统或策略机器人已经完成。
