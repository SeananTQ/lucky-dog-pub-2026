# 捣乱德州第二阶段：主场景本机试玩

玩法规则见[捣乱德州玩法设计](../game-design/捣乱德州玩法设计.md)，纯规则核心见[第一阶段说明](mischief-poker-core.md)。本文记录界面接入、开发测试入口及验收边界，不决定正式多人开局、准备或经济规则。

## 试玩入口

1. 从开发启动器选择“Steam 模拟环境”。
2. 打开“联机”页，加入默认模拟房间，或加入有陪伴小狗的陪伴房间。
3. 成员列表下点击“捣乱德州 · 本机试玩”。房间至少需要两名成员，本地准备阶段和房间请求进行期间不能开始。

该入口只在显式 Mock 环境提供。真实 Steam 房间不显示该入口，也不会向其他玩家发送测试牌局。按钮在正式 Release 中隐藏；调试驱动仅在 `DEBUG && !DEMO_BUILD && !RECORDING_BUILD` 下编译。

已经下注、尚未结束的单人牌局需要先完成并领取奖励。不能用试玩入口清空单人手牌或绕过结算。试玩进行中再次点击入口返回同一场试玩，不重新收取底注。

## 当前交互

- 复用实际扑克主场景、现有牌桌、手臂、卡牌素材及全屏／半屏联机宿主。
- 座位按进入试玩时的固定名单分配，与小狗摆放位置无关；首局庄家为当前房主。试玩期间的成员、成员身份、房主、房间或房间玩法发生变化时，结束本机试玩并清理界面。真实网络重连与换主恢复留给后续阶段。
- 自己的两张暗牌显示在手臂附近。其他小狗右侧显示两张牌背、座位编号、筹码和庄家／当前回合标记；结算时才展示其手牌正面。
- 开局先播放手牌合拢落下、展开动画，再从左向右依次发放五张公共牌，包含单人扑克的落地阴影、缩放及翻面节奏。发牌中禁用公共牌和手臂操作；当前内存试玩驱动也暂停推进回合时钟，动画结束后再开始计算行动时间。
- 牌局状态提示移到扑克区域底边，横向铺满牌桌，可覆盖手臂但不拦截输入；字体撑高时向上扩展，不把提示挤出底边。
- 公共牌区显示五张明牌。当前玩家最多点击两次，可连续点击同一槽位恢复原牌；点击手臂结束剩余操作。整回合 15 秒，第一次操作不延长期限。
- 所有其他成员由本机测试驱动自动操作。随机模式只做简单合法翻牌或结束操作，用于界面验收，不是正式扑克机器人策略。
- 每人结束操作后，下方状态条伸出“翻牌 ×2”“翻牌 ×1”或“PASS”，下一位直接继续行动。最后一人结束后，先等最后一次翻牌播完并短暂停留，再统一收回状态条、补牌、整理公共牌、亮手牌和显示牌型，最后展示赢家并派彩。结算结果包含各座位的牌型与所得筹码，显示下一局庄家及是否逆序；列表可滚动，操作按钮固定在列表外。
- 左侧游戏信息面板显示牌局筹码、当前局数和奖池、庄家、行动顺序、玩家状态与结算结果。分组小标题使用较小的强调色文字；调试控制不放在该面板中。
- 全部赢家派彩完成后，游戏信息面板才显示“下一局”。点击后先回收公共牌和手牌，必要时让庄家 D 标记飞向下一位，标记到位后才开启新局并扣底注。初始每人 1000 筹码，每局底注 100，余额沿用；有人不足底注时保留结果、不扣款、不自动补款，提示无法开始下一局，可从 Mock 面板结束并重新开始试玩。
- 试玩筹码和系统收走的平分余数只在内存牌局中计算，不读写单人筹码、Steam Stats 或存档。退出试玩恢复单人筹码、赔率栏、下注筹码和操作引导入口。
- 试玩期间暂停单人欢迎提示、便签和自动操作提示，不替玩家完成这些引导。顶部仍保留牌型帮助、聊天及回桌宠入口，暂时隐藏不适用的单人操作引导。打开模态界面或聊天输入时不能操作公共牌；牌局计时仍继续，需停表时使用测试暂停。
- 返回桌宠不会退出试玩；回来后恢复同一手牌和余额。其他小狗沿用现有自由拖拽、画布层级及位置交接；其卡牌区域计入边缘约束和拖动命中范围。

## 开发控制

### 独立翻牌与收尾动画场景

在 Godot 打开 `res://Scenes/Dev/Labs/PokerCardAnimationLab.tscn`，按 **F6** 运行当前场景。此场景用于反复调整捣乱翻牌和补牌收尾的观感，不运行正式牌局、Steam 或账号存档。已验收的默认水平翻牌与整理节奏已接入主场景本机试玩；实验场景的调节值不会自动覆盖主场景。界面结构位于场景中，可在编辑器调整。

- 点击任意牌或按数字 `1–5`，反复翻同一张原牌。可切换水平／垂直翻牌，调整随机倾角、位移、翻牌时长与播放速度。最后操作的牌位于其他公共牌顶层，重叠处的点击顺序也一致。
- 顶部提供全正面、两张背面、全部背面预设。选择预设会重新发牌；“重置 / 新牌桌”或 `Esc` 可随时取消动画并复位。
- “完整收尾”或空格：背面牌换成牌堆中尚未发出的新牌，水平翻正；没有背面牌则等待同样的翻牌时长。随后五张牌从各自当前姿势，依次倾斜、轻抬再回正，不提前跳回整齐姿势。
- “重播上次收尾”或 `R` 保留上次收尾前的牌、歪斜位置及补牌结果，应用当前调节参数。勾选循环后可反复比较；重置或单独整理会清除旧的重播内容。“只播整理”不补牌，也不改变正反状态。
- 收尾默认沿用单人扑克提醒的节奏：各牌错开 0.05 秒、轻抬 0.14 秒、回落 0.19 秒。整理角度与错拍间隔可调；慢放时音效同步降速。“复制参数”便于在反馈中记录当前设置；本轮参数不写入玩家设置，重新运行恢复场景默认值。
- 整理音效为 `Audio/SFX/Card_PokerBoardStraighten_1.ogg`，当前复制自 `Card_PokerHandHint_1.ogg`。每次整组整理只播放一份，包括全正面且原本没有歪斜的情况；后续可单独替换，不影响原单人提示声音。同帧多张翻牌合并翻牌音效。
- 独立窗口默认保留屏幕底部 200 像素用于反馈，顶部提供拖动标题、适应屏幕、最小化与关闭。窄小窗口时右侧调节区允许滚动。

针对性逻辑检查入口：

```powershell
godot --headless --path lucky-dog-rise res://Scenes/Dev/Labs/PokerCardAnimationLab.tscn -- --poker-card-animation-lab-smoke
```

检查场景引用、素材、翻牌不换牌、补牌唯一性、全正面等时停顿、整组音效次数、重播一致性、重叠层级与点击顺序、中途重置和连续收尾复位。该检查直接推进动画时间，不代表视觉或音画节奏已验收。主场景的局间流程另由下面的专项入口验证。

### 主场景 Mock 控制

开始本机试玩后，顶部 Mock 面板中会显示并选中“扑克”页签。若 Mock 面板已被关闭，可从系统面板 Debug 页重新开启 Mock 面板；开始试玩不会强制打开已关闭的 Mock 面板。“Steam”页签继续保留原有平台模拟功能。

“扑克”页签提供：

- 暂停／继续：冻结／恢复本机牌局时钟和自动操作，暂停时仍可手动翻牌、结束回合或单步操作；已经触发的视觉演出仍正常完成，包括收牌和换庄。返回桌宠或被模态界面遮挡时，局间展示进度等待可见后继续。
- 机器人一步：让当前其他玩家做一次合法操作，或在待补牌阶段执行结算；不能替本机玩家操作。
- 当前超时：把时间推进到当前玩家的回合期限，通过正常超时逻辑结束该回合。
- 下一局牌堆预设：随机牌、公共牌平局、庄家获胜、其他人获胜。预设从下一局生效；非随机预设中其他小狗自动结束操作，便于观察指定结算。玩家若主动更改公共牌，预设的胜负可能随之改变。
- 结算显示预设：增加相同两对 K 胜公共牌 5、相同对子因观察者而异、不同两对不放大副牌、其他人平局而本机落败、本机独赢。独赢预设复现公共一对 K、本机 A 副牌获胜且不放大的情况。仍从下一局生效，直接结束回合可以保留预设结果。
- 牌手面板样例：可将首位其他参局玩家临时显示为等待入局或掉线托管。此选项只检查外观和组合状态，不改变本局名单、手牌、超时、行动、筹码，也不等于已经实现正式联网的中途入局或托管。
- 结束试玩：清理当前内存牌局并恢复单人显示，不退出联机房间。

切换页签或关闭 Mock 面板不暂停、不重开牌局；暂停状态与下局牌堆预设保留。返回桌宠时仍按既有规则隐藏整个 Mock 面板，返回扑克可继续操作同一场试玩。试玩结束或因房间变化失效时，清理扑克调试页内容并返回 Steam 页签；无试玩时隐藏扑克页签。

调试页长说明在页签内部滚动，不增加顶部 Mock 面板高度；游戏信息面板仍使用原有 600 设计高度，结算名单在内部滚动。

中文为当前试玩文案，英文为临时回退文案；英文玩法正式名称及其他语言不在本阶段定案。

`RoomPokerTableView.SkipDealAnimationForTests` 是仅 Debug 编译提供的内部开关，默认关闭，不提供玩家设置，也不持久化。自动状态回归可临时开启以直接到达发牌完成的姿势；主场景专项仍会单独关闭此开关，验证真实发牌动画、不同持牌姿势与中断清理。

## 牌手面板与结算展示

具体显示规则及占位图标位置见[牌手面板设计](../game-design/牌手面板设计.md)。本机信息放在手牌右侧，其他小狗的信息放在各自手牌下方。固定编号、余额、庄家 D、行动倒计时、胜者图标和底色分别显示；不重复姓名。

绿框表示本机的强调牌，原亮度表示当前展示赢家的强调牌，其余牌压暗。按牌型核心展示；本机落败且核心点数相同时，增加双方首次分出高低的副牌，并将赢家对应牌以过冲动画放大至 120%。本机独赢且需要副牌分胜负时，以最强落败者为内部比较依据，静态补亮并框出本机的决胜副牌，不放大、不展示对手排名或增加对比步骤。高牌和本机参与平局时使用完整最佳五张。相同牌力的公共牌按左槽位优先稳定选择。

平局赢家按本局行动顺序逐位展示，所有赢家保留同等胜者标识；筹码动画只表现已完成的结算。每人 2.4 秒，展示一次后停留在末位赢家。全部派彩结束前不能跳过到下一局，不重复收付筹码。

牌手面板预留完整下方状态条与外挂标记的范围，其他小狗的整块面板向上移动，保持原下边界；状态条伸缩不改变拖拽范围。庄家 D 与胜者占位图标挂在主底板外侧，牌型改在深色独立状态条内显示浅色文字。

### 局间演出与续局

- 玩家操作沿用独立场景验收的水平翻牌：0.16 秒，最终角度相对原始姿势随机 ±14°、位移 ±10 像素，不累计漂移。最后操作的公共牌同时置于绘制和点击顺序的顶层。
- 最后一次翻牌完成后保留行动反馈 0.55 秒，状态条用 0.20 秒收起。系统对背面牌补入新牌并水平翻正；全正面时同样等待 0.16 秒，不更换牌、不播放翻面声音。
- 整组整理必播：错拍 0.05 秒、轻抬 0.14 秒、回落 0.19 秒，从当前歪斜姿势过渡到整理倾角后回正，整组只播放一份 `Card_PokerBoardStraighten`。
- 整理后才公开其他手牌，等翻面完成后伸出牌型状态条，再进入原有赢家展示和派彩。左侧筹码和结算信息同步遵守展示阶段，不能在补牌之前泄露结算；每位赢家的余额在其筹码飞行结束后显示入账。
- 回收公共牌沿用单机的向左滑动半张牌、0.32 秒渐隐、每张错开 0.04 秒；两张手牌相对各自最终姿势向下移出渐隐。旧牌回收后，换庄标记用 0.60 秒飞向新庄；同一玩家继续坐庄时跳过跨面板飞行。
- `PokerRoundPresentation.PauseAfterPayout` 是代码内部的续局策略，开发试玩默认 `true`。设为 `false` 时使用同一套自动收牌、换庄、发牌流程；两条路径均要求所有余额不小于底注。尚无正式 Steam 扑克入口，也不增加玩家设置或自动补款。

以上数值是当前体验初值，不改变规则层的 15 秒行动时限或牌局结算结果。

绿框与亮暗由公开结算结果和本机身份派生；显示层不读取未公开的其他玩家暗牌。不同客户端可以有不同强调牌，但不能改变权威胜负或筹码。

## 程序边界

- `MischiefPokerPreviewSession` 仅是开发环境的内存权威适配器：复用第一阶段规则，不复制发牌、判型、超时或轮庄算法。其预设牌堆不能成为未来客户端可调用的网络命令。
- `ModeManager.MischiefPreview` 负责入口、房间身份校验、生命周期和主场景接线。正式 Steam 传输尚未接入。
- `RoomPokerPanelView` 只展示牌局信息并发出下一局请求；`Scenes/Dev/Debug/RoomPokerDebugPanel.tscn` 与 `RoomPokerDebugPanelView` 单独承载测试控制，由 Mock 面板提供页签。调试视图仅在 `DEBUG && !DEMO_BUILD && !RECORDING_BUILD` 下编译，正式牌局信息视图不依赖测试控制。
- `RoomPokerTableView` 只消费本机 `PokerPlayerView`；其他小狗的展示只从公开视图的结算结果取牌面。未结算时不向远端卡牌控件提供真实暗牌。
- `PokerRoundPresentation` 统一管理当前客户端的演出阶段和显示快照。规则结算仍一次完成；它只延后显示补牌、公开手牌和入账余额，不重复判牌或修改真实余额。收牌与标记交接结束后只发出一次下一局请求，拒绝时返回结算检查状态。
- `RoomPokerCardView` 使用快照驱动可取消的翻面 Tween；不使用脱离节点生命周期的延迟计时器。换局、取消和退出后旧翻牌不能覆盖新快照。
- 手牌出现动画只改变相对于场景最终姿势的临时位置、角度和透明度；公共牌发牌使用节点绑定的 Tween，同步管理落地阴影。首次收到结算快照或返回同一局时不重播开局动画。
- 联机同帧翻牌通过 `AudioManager.PlaySfxOncePerFrame` 按组共用一份音效；正常逐次点击和公共牌间隔发放仍分别播放，其他玩家手牌出现不额外叠播。普通单人音效入口不变。
- 开局等待仅由当前本机试玩驱动处理；正式联网时必须由权威牌局提供发牌阶段，不能让各客户端通过自己的动画暂停服务器的行动时钟。
- `PokerShowdownPresentation` 只派生公开结果的强调牌，按等价公共牌左优先选取，判型仍复用原规则核心；`PokerShowdownSequence` 缓存每个结算视角并管理一次性的赢家展示顺序，不逐帧重算最佳组合。
- `RoomPokerHandView` 负责可叠加的身份／状态标记和两张手牌；`RoomPokerCardView` 将牌面压暗与独立绿框分开，结算副牌 Tween 不缩小败者，换牌或换局时取消旧动画。
- 副牌放大以场景原始底边中点为锚点，同时计算缩放与位置补偿，过冲全程保持底边不下沉；不修改原有旋转中心，兼容倾角及非默认缩放。结束强调、换牌或开始发牌时恢复位置和缩放，重复快照不累计偏移。
- `RoomPokerPayoutView` 复用现有筹码图片，按当前牌桌和目标面板的位置绘制飞行，不参与输入命中或筹码入账；目标拖动时仍跟随最新位置。
- 界面结构保存在 `Scenes/Rooms/Poker/`，字体样式在 `DefaultTheme.tres`。新增 Godot 节点类纳入混淆保留列表；Demo／录屏沿用 `Scenes/Rooms/*` 与 `Scripts/Rooms/*` 的排除规则。

- `dotnet run --project tests/MischiefPoker/MischiefPoker.csproj -c Release`：原规则核心检查加本机驱动检查，覆盖 2～6 座位、预设、暂停、自动机器人、超时、守恒和强制轮庄。测试失败会写出日志并返回非零退出码，避免未捕获 CLR 异常触发 Windows 错误对话框。
