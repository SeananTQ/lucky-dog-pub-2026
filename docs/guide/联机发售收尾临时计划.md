# 联机发售收尾临时计划

本文件记录发售范围调整及收尾顺序，合并主干后可归档。范围按主人已确认的决定执行；具体玩法和实现约束仍以关联文档为准。盘点基线为 `codex/steam-lobby` 的 `5a96bd5`，不是已完成发售验收的声明。

## 已确认的发售范围

- 保留多人房间，以及一起聊天、各自工作、陪伴房间、房间内各自玩单人扑克等现有公开功能。
- 捣乱德州的代码和资源保留在支持联机的游戏包中，继续用于内部开发及邀请测试；本次不要求把它完善到公开玩法的程度。
- Dev 包在调试面板提供捣乱德州入口开关。普通玩家没有该调试入口，不能自行从公开玩法菜单发起捣乱德州。
- 普通玩家可以接受邀请进入测试房间并参加捣乱德州，不要求安装 Dev 包或打开调试开关。开关控制发起入口，不能作为参与整个玩法的总开关。
- 测试房间不出现在公开房间列表，也不参与随机加入，通过邀请控制测试范围。这不改变普通社交房间的公开与加入规则。
- 受邀玩家留在测试房间时保留参局和必要管理能力，接任房主后不能因没有 Dev 面板而卡住房间；离开测试房间不永久解锁发起入口。测试双方仍须使用兼容的客户端版本。
- 继续保留 Demo／录屏对联机功能的既有隔离。不会为了隐藏捣乱德州而关闭全部联机，或从正式包裁掉受邀游玩所需的逻辑和资源。

## 第二步结果：开发入口与邀请测试

- Dev 的系统面板 Debug 页增加「开放捣乱德州测试入口」，默认关闭，保存本机选择。开启后显示玩法选项和显式 Mock 环境的本机试玩入口，并允许 Mock 联机页重置测试房。关闭后禁止新的发起或确认，包括旧菜单信号；已经参加的牌局和正在运行的试玩不被中断。
- Playtest／Release 的发起能力固定关闭，不读取 Dev 设置来解锁。正式包保留牌局、准备、旁观／入座、聊天、恢复和必要管理代码；普通玩家受邀后显示真实当前玩法，接任房主后可开始、继续、重开或切回社交玩法。离房后没有永久解锁。
- 房主发起切入捣乱德州的投票前，先把 Steam 房间设为「仅限邀请」。设置失败则不发布投票，不改变当前玩法。切换权限不请出已有成员，他们仍可投票并参与。
- 正在投票切入或当前已是捣乱德州时，房间进入权限保持仅限邀请；服务层也拒绝旧界面或其他入口重新公开。列表查询额外过滤这两种房间，随机加入使用同一结果；不依靠单纯隐藏本机条目。
- 房间码继续表示房间地址，不代替邀请许可。加入、重连、人数上限、版本兼容和禁止名单仍由既有 Steam 加入流程判断；客户端不会因为没有 Dev 开关就拒绝已经获准加入的玩家。
- 取消投票、投票超时或切回聊天后，房间仍保留仅限邀请，避免突然向公众开放。退出测试玩法且没有待处理的测试投票后，房主可自行改回公开。新建普通房间仍默认公开。
- 换主保留测试房间的私有权限；开关只影响本机发起能力，不进入网络协议，也不改变已保存的牌局恢复副本。Demo／录屏的联机编译隔离继续保留。

测试使用既有房间实验室与主场景检查，没有增加新的测试场景。详细验证结果与真实 Steam 验收边界记录在[房间参局与网络同步](mischief-poker-network.md#发售入口与邀请测试)。

## 第一步结果：发售前必做

此处的优先级替代旧 A／B 列表的开发顺序，原编号仍用于追踪。P0 先完成，P1 随后完成；验收发现的新缺陷按影响重新排序。

- **P0：Dev 发起入口和邀请测试边界。** 对应第二步，现已实施，待第四步真机验收。`BuildCapabilities.SteamRooms` 继续控制整个联机能力，独立的 `CanInitiateMischiefPoker` 只控制发起权限，不关闭受邀运行。
- **P1：公开联机界面的本地化缺口。** 正式语言表 `InGameRoomText.csv` 中，有 9 条联机名称／显示设置相关记录仍只翻译了简体中文和英文，其余 18 种语言填写英文。覆盖联机页签、房间列表标题、显示设置标题、全屏自由／半屏紧凑及说明、入房锁定与操作中提示。沿用当前名称发售还是先调整名称，应在补译前确认；本步不翻译，也不把全部房间文本误判为缺译。
- **P1：公开功能验收发现的缺陷。** 优先保证普通房间、单人扑克、桌宠、盲盒及个人资产路径。本次对已记录事项的盘点，没有发现另一条已经明确复现、仍未修复的普通房间阻断问题；这不等于实际运行已经没有问题，下节验收仍需完成。

## 第一步结果：已实现，发售前重点验收

以下是验收任务，不是要求重做已完成实现。主人已有通过记录继续有效，只补尚未覆盖或被后续改动影响的路径。

- **P1：普通房间完整流程。** 普通创建只有本人；空列表陪伴入口与随机加入无目标时进入陪伴房间，网络失败不冒充空列表。核对陪伴房主交接、真人加入与陪伴让位、六只上限、普通房间邀请／权限／请出和离房恢复。B3 中局间入座属于捣乱德州，但普通陪伴房间的名额与让位仍在公开范围。
- **P1：普通房间换主及断联恢复。** 核对聊天房主离开后的新房主权限、断网重连、主动离房和被请出后不被错误自动拉回。B4 的暗牌恢复与托管测试可以延期，这些普通房间路径不能跟着延期。
- **P1：联机宿主与单人扑克共用显示。** 全屏自由／半屏紧凑、拖拽推动与回拉、任务栏吸附、面板及气泡避让、透明命中、扑克往返保留位置、离房恢复普通窗口。实体多显示器／混合 DPI 尚缺设备验收，保留这一限制，不以坐标模拟代替，也不据此无依据扩大开发范围。
- **P1：邀请测试的最低可用性。** 第二步完成后确认普通包无法主动发起、公开列表和随机加入找不到测试房；兼容的普通包可受邀进入、准备／入座、完成一局、正常离开。补查测试房换主及退出后的入口状态，避免调试开关影响正在使用的玩法。更广的捣乱德州规则与极端恢复矩阵留到后续。
- **P2：A3 房间列表自动刷新。** 代码、逻辑和假 Steam 传输已检查；真实 Steam 的新增／消失／人数变化、滚动及点击稳定、隐藏停止轮询仍待验收。
- **P2：A4 普通成员入退场与姓名栏稳定。** 入退场已实现；任务栏姓名栏随舌头抖动已修复。补普通聊天房间的人工观感检查，不要求重复已通过的离房托管用例。
- **P2：A5 精简后的玩法切换提示。** 一起聊天／各自工作也使用这套投票界面，检查精简文字、多语言布局以及欢迎／帮助／盲盒占用时的等待，不因捣乱德州隐藏而遗漏。
- **P2：大额筹码显示修复。** 数值、倍率及布局专项检查已通过；主人补看普通扑克信息面板的大数显示和恢复正常字号的观感。只验收显示，不改变个人筹码或账本。

## 第一步结果：捣乱德州后续开发

保留包内功能和待办，不要求本次全部完成。若后续发现这些代码会破坏普通房间、单人玩法或个人资产，再把相应缺陷提升为发售问题。

- **A2：笔记本狗爪动画流畅度。** 暂缓专项排查，尚无已确认的根因；不能把它直接归因为网络，也不为此增加本轮性能改造。
- **A1、B2、B3 的剩余玩法体验与联调。** 电脑思考节奏、暂停成员按钮、局间入座、参局陪伴让位等已有实现保留；未覆盖的捣乱德州验收继续留档。
- **B4 的扩展真机验收。** 断网、Alt+F4、连续换主、恢复副本异常等牌局测试后续安排；既有 Mock 通过记录保留。普通房间换主重连及第二步修改直接影响的邀请链仍按前节验收。
- **B5：准备状态强调。** 已有状态措辞保留，绿色等视觉强调后续讨论。
- **B6：正式牌局经济。** 继续使用临时每人 1000、每局底注 100 的场内筹码；不足底注、补充筹码及正式补偿规则延期，保持与个人／盲盒筹码隔离。
- 牌手面板正式美术、占位图标替换、玩法文案与英文名完善、场内排行榜、共享房主牌桌／背景、规则可配置及其他扑克玩法，按各设计文档继续推进。
