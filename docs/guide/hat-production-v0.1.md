# 帽子临时生产 v0.1

本版于 2026-10-23 收束现有迭代，供主人先开展 Illustrator 重绘参考稿生产。它包含可执行的选参考、生图、自检及有限返修流程，不宣称已经达到 90% 成功率。v0.1 的提示词是根据最新反馈整理后的新版本，本次没有再生图验证其效果。

## 直接使用

在本项目对话中调用：

```text
使用 $lucky-dog-hats，生成一顶第二档棕色牛仔帽，哑光毡材质，
帽带加一个简洁方扣。做新设计，按临时生产 v0.1 选项目参考、
生图并视觉自检，保存原图、提示词和需要我重绘时修改的地方。
```

通常只需给帽型和特殊想法；档位、材质、经典造型已有要求时一并说明。AI 会整理任务卡，无需主人填完所有字段。批量时列出帽型与数量即可；默认一帽一图，整体失败最多针对性返修一次，保留所有尝试并交付剩余问题。需要其他尝试次数时直接指定。

Skill 位于 [lucky-dog-hats/SKILL.md](../../.agents/skills/lucky-dog-hats/SKILL.md)，支持项目帽子任务的自动匹配，也可以显式用 `$lucky-dog-hats`。若当前会话未发现刚新增的 Skill，可直接要求读取该文件使用。

## 当前题材范围与后续方向

主人于 2026-10-24 明确当前以现实中存在的帽型为主。可制作保留帽型识别的主题变体，例如已获认可的南瓜贝雷帽：其核心是画家贝雷帽本来就有的小尾巴正好对应南瓜梗，让帽型原有结构自然承担主题特征。

纸袋、蝴蝶、独角兽角与鬃毛等特殊头饰留作后续需求。另一个后续方向是表达玩家状态的头饰：卷纸表示去上厕所，满电电池表示活力充沛，空电电池表示今天上班很累，汉堡或拉面表示去吃饭。本次仅记录题材及表达用途，不启动这些设计，也不推定需要实现自动状态切换。

## 本版采用的边界

三档沿用主人定义；第一、第二档可以接近，第三档主要保留与名人或经典造型有关的识别特征。所有档位采用共同的简洁色块画法，不通过厚涂、密集亮暗或堆附件表现高级。

左上光源，必要时保留材质高光、褶皱与凹陷暗部；不全面禁明暗。简化先删冗余，不删消防帽顶部凸起等必要构件。帽子保持自然戴在正面狗头上的可见面；学士帽不露帽板顶面是专项规则，不限制其帽冠下沿圆尖。

验收先看整体画风，再看身份、材质、结构与佩戴。约 10% 瑕疵指可明确描述的局部修复工作量，不抵消整体画风和主体结构失败。AI 初评、主人确认、实际佩戴验证分别记录。

本项目使用子 Agent 时沿用 `GPT-6.1 SOL / high`；生图走内置工具，其底层模型版本不可由这个设置指定。单个任务不强制多 Agent。使用高级模型不作为此版本成立的前提。

## 产出与交付

默认输出到 `assets/output/hat-production/YYYY-MM-DD/<批次名>/`，包含编号原图、逐字提示词、参考来源与简短视觉评审。原图与失败尝试都保留；生成稿不覆盖正式 Headwear 或 ItemIcon，不自动入库。

主人拿到设计稿后在 Illustrator 重绘、简化、调整狗头位置并导出正式素材。生成阶段的“可用”指设计参考可用，不代表已完成游戏运行时适配。
