# 便签提示规则

记录每条便签的触发与完成差异，作为后续 Excel 数据驱动的规则依据。目前规则仍由业务代码接入，本文不引入新表。

## 共通规则

- 按账号、按稳定 Key 独立保存；触发和完成立即写入 `account_state.cfg` 的 `persistent_tips` 节。
- `Unseen` 表示未触发，`Active` 表示仍需提示，`Dismissed` 表示已完成、不再需要提示。沿用现有枚举和值，最后一态不意味着玩家一定亲手点击过便签。
- 暂时隐藏不等于完成：切回桌宠或打开欢迎、帮助、操作说明、庆典对话框、盲盒表演时隐藏，返回可操作牌桌后恢复未完成便签。正式记录跨重启保留。
- 点击便签本身不操作牌桌、不触发窗口拖动、不算有效扑克操作，也不算使用帮助栏。
- 完成条件必须逐条指定，不可统一采用“做过相关操作就关闭”。

## 手臂换牌便签

- Key：`poker_draw`；正文 Key：`PersistentTip_PokerDraw`。
- 触发：第一次实际点击卡牌，将正面翻到背面。仅发牌、自动示例牌动画不触发。
- 完成：**只能由玩家手动点击这张便签**。
- 点击手臂、换牌、结算、得分、使用帮助栏、打开操作引导，都不完成这张便签；不根据历史操作或熟练度自动补记完成。
- 原因：不知道手臂可以确认换牌会使玩家无法继续，需保留明确提示，直到玩家主动确认。
- 位置：1200 坐标系 `(24, 1030)`，宽 240，底边固定、向上展开。现有 20 种语言。

## 帮助栏入口便签

- Key：`poker_help_bar`；正文 Key：`PersistentTip_PokerHelpBar`。
- 触发：尚未使用帮助栏时，实际发生 20 秒无有效操作的快捷栏自动展开提醒。普通悬停展开、欢迎确认后的 5 秒展开不触发。
- 完成条件满足任一项即可：玩家手动点击便签；或成功触发栏内任意功能按钮（玩法帮助、操作引导、回到桌宠）。
- 使用栏内功能时，尚未触发的便签直接补记完成；已显示的便签立即关闭并记为完成。之后即使再次满足激活条件，也不重新显示。
- 旧账号兼容：初始化牌桌时，已有 `poker_quick_bar_used=true`（含既有旧档迁移结果）的账号，补记该便签完成；同时覆盖缺失便签记录和遗留 `Active` 记录。不影响手臂便签。
- 仅悬停展开、点击欢迎提示的「好的」、从赔率表打开帮助，不算使用帮助栏，不完成便签。
- 手动关闭便签不会反向标记帮助栏已使用；未用过栏内功能时，原有 20 秒闲置展开提醒仍可继续。
- 位置：`(24, 104)`，宽 380，顶边固定、向下展开。本轮仅中英文正文，其他语言暂用英文，待主人验收后翻译。

## 调试与后续配表

- 临时 `_repeatPersistentTipsOnStartup` 开关只重建内存便签状态，不撤销帮助栏使用记录。若需要重播完整发现流程，同时开启 Debug 的「启动时重置快捷栏发现」后重启；否则已有使用记录会再次将帮助栏便签置为完成。
- 单独「重置快捷栏发现状态」不撤销便签的完成记录；正式发布不采用便签临时重播。Mock 与本地测试继续使用隔离状态。
- 帮助栏逻辑专项入口：`PersistentTipPreview.tscn -- --help-bar-completion-only`，检查完成、旧记录兼容及不会误完成手臂便签；不执行手臂动画或多语言回归。布局专项入口为 `--help-bar-tip-only`。
- 将来可配字段：稳定 Key、正文 Key、触发事件、允许手动关闭、业务完成事件、历史完成判据、目标界面与锚点。事件应引用有限的业务标识，不把任意条件表达式写进 Excel；存档 Key 和已有完成状态需继续兼容。

通用显示、输入协调和实现入口见[交互提示系统说明](交互提示系统说明.md)，帮助栏自身行为见[扑克玩法帮助说明](扑克玩法帮助说明.md)。
