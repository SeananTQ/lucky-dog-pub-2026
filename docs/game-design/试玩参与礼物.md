# Demo 与 Playtest 参与礼物

正式版 LinkTree 提供两个独立的领奖入口。Steam 记录的对应 AppID 累计游玩满 2 分钟即获得资格。Demo 为 `5220880`，Playtest 为 `4972240`，正式版库存归属 `2583700`。参与顺序不限，玩家在购买正式版后试玩 Demo 也能回来领奖。

## 入口与奖励

- 两份尚未领取的礼物都显示中性礼盒。Demo 排最前，Playtest 排在常用活动、社区和商店链接之后。库存就绪后可点击，悬停提示“点击让 Steam 核验并领取”。只有玩家点击才向 Steam 请求对应礼包。
- Steam 核验账号在对应 AppID 的游玩时长。玩家可以卸载试玩版或更换设备。两份礼物独立发放，每份奖励展示完成后收起自己的入口。
- Steam 已处理请求且完整库存确认没有发奖时，Demo 提供试玩链接，Playtest 提示礼物面向测试参与者。入口保留，补玩后可回来再点。网络或库存读取失败时提示 Steam 奖励暂时不可用，重连后可以重试。
- Demo 一次发放庆典奖池的 15 件装扮和完成奖励学士帽，每件一份。领取成功后显示三列物品图标，可滚动查看全部 16 件，确认后收起 Demo 入口。Playtest 暂用胖黑柴（Item 1002），沿用单件领取动画。两个入口使用临时 Banner。

## 渠道行为

- Dev 默认两项都有资格，支持从实际页面走完领取。每次启动重新获得两次独立的测试机会。
- Playtest 和 Release 使用各自应用的 Steam Inventory。点击后调用 `AddPromoItem`，按礼包的 `played:AppID/分钟` 规则发放装扮和独立永久回执。服务端确认回执和配置的奖励后展示结果；历史回执在重启或换机后恢复已领状态。0.6.11 测试阶段的会话领取没有写入 Steam 回执，切换后以当前应用的 Steam 库存为准。

## 配置与验收

资格规则为 `played:5220880/2` 和 `played:4972240/2`。2026-11-24，发行商时长查询确认测试账号的 Demo 累计 1147 分钟、Playtest 累计 565 分钟。Steam 只读促销资格列表未返回这两个礼包，0.6.10 测试包重启后仍停在核验状态。该账号可用于双资格回归；另需覆盖未参与、仅 Demo、仅 Playtest。Playtest 和 Release 的库存配置分别发布。

本轮使用 Luban 副本导出验证策划表、游戏数据和 Steam schema。先验证 Dev 双领奖、同次运行防重、重启重领、Demo 与 Playtest 可见性及原 LinkTree 入口。Playtest 真实资格单独记录，上传由主人操作。本轮开发不制作安装包。

## 本次配表与交付

- Demo 入口 1012 使用 `FixedItemList`，将学士帽和其余 15 件装扮全部填入 `RewardItemIds`。Playtest 入口 1013 使用 `FixedItem`，在 `RewardItemId` 中填入单件装扮。两行 `HideWhenIneligible` 都填否，`SortOrder` 分别为 1 和 140。
- Demo 领取礼包为 `601012`，内含回执 `501012`。Playtest 领取礼包为 `601013`，内含回执 `501013`。两个 LinkTree 子段优先使用与入口一致的末三位，方便人工查找。完整分段约定见 SteamItemDefIdRange 表。
- 2026-11-23 已将审定配置合回 [Items.xlsx](../../luban-excels/xlsx/Items.xlsx) 和 [__enums__.xlsx](../../luban-excels/xlsx/__enums__.xlsx)。从正式表重新导出的 23 个 JSON 和 65 个 C# 文件均与游戏项目一致，两个渠道的 SteamDef 与此前验收的文件逐字节一致。
- 本地 Godot 回归使用实际 LinkTree 面板和受控库存结果，覆盖领取反馈、防重复、重新启动的会话状态、补玩后领取及正式版读取独立回执。Steam 历史资格查询和真实发放需在后台发布后分别验证。
- Godot 编辑器预览可按 F5，在开发者启动器选择“Steam 模拟环境”和“常规 Debug / Playtest”，启动游戏后打开系统面板的 LinkTree。两个入口会直接显示，领取反馈播放后分别收起，停止运行再启动可重测。
- 真实资格联调使用 Playtest AppID `4972240` 的[物品定义](../../lucky-steamworks/steam-item-def/generated/steam-itemdefs.playtest.json)。相对 11 月 16 日已提交的定义，本次只新增上述两个礼包及两张回执。学士帽 `102034` 和香槟 `109004` 的英文名已在当时的生成文件中。`generated/uploaded/` 由人工登记，后台状态以 Steamworks 的记录为准。
