# 物品默认穿戴规则

## 装备槽位

`EquipmentSlotConfig` 中存在对应 `ItemType` 才表示该类型可以独立穿戴。不可空闲槽位必须装备一个玩家已拥有的有效物品；可空闲槽位默认不装备，除非初始内容明确要求。

眼镜不再是独立装备槽。当前设计将眼镜素材绑定在 `DogSkin.FixedEyewear` 中，作为小狗皮肤的一部分运行时分层显示。历史眼镜物品仍可保留在 Steam 库存和本地拥有数量中，但不会出现在背包页签，也不能再次穿戴。

## 获得物品后的自动穿戴

玩家通过盲盒或其它正式来源获得新道具时，如果该物品所属的有效装备槽当前为空，可以自动穿戴。如果槽位已经有装备，不自动替换，只显示 `New`。

自动穿戴的新道具仍可显示 `New`，表示这是刚获得的物品。玩家在背包中点击已穿戴且带 `New` 的物品时，只清除 `New`，不会立即卸下。

背包只显示当前 `EquipmentSlotConfig` 支持且未被隐藏的部位页签。空页签显示明确的空状态提示，避免玩家误认为界面卡住。

## 已下架物品

`AcquisitionType=Retired` 的物品遵循以下规则：

1. 保留玩家已有数量和 Steam 库存实例，不执行追溯删除。
2. 不参与新的发奖、自动穿戴、随机穿戴或轮换获得道具。
3. 不产生新的获得类成就或玩家统计；已经形成的历史统计不扣除。
4. `IsHiddenInBag` 仅控制背包显示，不能代替下架状态。

老存档中的独立眼镜穿戴记录会在存档加载归一化时安全摘除。眼镜所有权继续保留；因为入口已经隐藏，其无法访问的 `New` 标记同时清除。其他有效槽位的穿戴不受影响。

## Dev 调试规则

全物品随机穿戴从装备槽位表支持的类型中选择候选，排除 `Retired`，并继续排除 `Special2`。

已拥有物品随机穿戴只从玩家已拥有且未下架的物品中选择，避免存量玩家重新穿戴历史物品。

轮换获得道具按 `EItemType` 枚举轮换，不以装备槽位表为类型来源；Dog 参与轮换。候选物品排除 `Retired`，并维持原有的普通可见物品限制，即只选择 `IsHiddenInBag=FALSE` 的物品。`IsHiddenInBag` 不承担下架语义。
