# 小狗系统参考

## 提示信号

狗根据补牌后的实际结果给提示（不是预设等级）。4 档信号：

| 信号 | 视觉 | 对话 |
|------|------|------|
| `Bored` | 打哈欠 | "*yawns* Not looking great..." |
| `Happy` | 摇尾巴 | "*wags tail* Feeling good!" |
| `LuckyEye` | 眼睛发光 | "*eyes light up* Something big!" |
| `TopTier` | 竖起耳朵 | "*ears perk up* INCREDIBLE!" |

## 流程

1. 发牌后玩家可点击小狗 → 狗评估当前保留策略并给出信号
2. 玩家在询问提示后修改选牌，触发 `2005 / HintExhausted`，继承沉默反应。
3. 玩家再次询问，触发 `2006 / RefuseHint`，继承拒绝反应。

## 爪子系统

- 默认：双手手背
- `ShowClawPalm()` — 切换到手心
- `ShowClawBack()` — 切换到 手背
- 爪子使用 `z_as_relative = false` 控制叠放层级

## 默认表情

`1001 / Default` 使用 `DefaultEyes`、`DefaultEars`、`DefaultMouse` 及双手手背。

## 当前数据职责

`DogSkin` 保存每只狗的素材配置，`DogReaction` 保存反应触发、参数继承、部件引用及公共动作。当前不新增性格映射表；同一反应通过不同 DogSkin 的字段值表现出角色差异。

`DefaultEyes`、`DefaultEars`、`DefaultMouse`、`DefaultNose` 是逻辑上的默认素材。`Eyes_NormalMood` 表示平常心情的眼睛，不等同于程序默认值。沿用既有 Mouse 拼写，不在本次改版更名为 Mouth。

三个 Asset 列按字符串读取，但现在字符串表示 DogSkin 字段名，不再表示 PNG 文件名。可引用字段如下：

- `EarAsset`：`DefaultEars`、`Ears_Normal`、`Ears_Drooped`。
- `EyeAsset`：`DefaultEyes`、`Eyes_NormalMood`、`Eyes_Bored`、`Eyes_Happy`、`Eyes_Admiring`、`Eyes_Stunned`、`Eyes_Signaling`。
- `MouseAsset`：`DefaultMouse`、`Mouse_Silent`。

`DogVisual.ResolveDogAsset()` 按部件显式映射到当前 DogAppearanceSpec 的属性，再结合该狗的 FolderPath 加载素材。字段值可以与字段名称不同。例如 MouseAsset 填 Mouse_Silent，DogSkin.Mouse_Silent 填 Mouse_Shy.png，赤柴最终加载 `res://Assets/v3/Shiba/Red/Mouse_Shy.png`。

- Asset 列留空：继承 AssetRef 的参数，最终无配置则使用该部件默认素材。
- 填写 `默认`：明确恢复当前狗狗的该部件默认素材。
- 被引用的素材字段为空：回退该部件默认素材。
- 无效引用或跨部件引用：中文日志警告并回退默认素材，不再把引用字符串补成 PNG。
- 文件名有效但实际文件缺失，不属于空字段回退，必须通过资源校验修正。

`OverrideHeadwear` 仍是资源路径，不属于上述三列。Bespoke 特殊入口仍由代码按行 ID 处理。新增可引用字段必须同步表、共享模型、显式解析映射、编辑器和测试，仅增加表列不会自动获得解析支持。

## 沉默与拒绝

`1007 / Silent` 使用 Ears_Drooped、Eyes_Stunned、Mouse_Silent。当前沉默嘴部素材为 `Mouse_Shy.png`，不是 Mouse_Sky.png。

沉默嘴部有配置时隐藏舌头并阻止桌宠吐舌及哈气动画；Rise 显隐不能重新显示该反应隐藏的舌头。恢复默认反应时恢复默认嘴部，舌头继续服从 Rise 显隐。Mouse_Silent 为空时回退默认嘴部并保持正常舌头行为。

`2005 / HintExhausted` 继承 Silent。`1008 / Reject` 仍使用 DefaultMouse，不等同于沉默；`2006 / RefuseHint` 和 `4001 / RefuseRefreshment` 继承 Reject。

WearGlasses 已从 DogReaction 删除，不保留配置墓碑，也不用于沉默。狗狗身份绑定的固定眼镜仍由 DogSkin.FixedEyewear 控制，不受该清理影响。

## 验证边界

`Scripts/Dev/Tests/TestDogSkinParts.cs` 属于 Godot 集成回归测试，不是纯单元测试。测试实例化真实 DogArea，读取正式表并遍历全部 DogSkin 和 DogReaction；部分关键结果有主动断言，包括坐标、嘴部切换、沉默继承、舌头隐藏及恢复、旧草稿迁移和 CSV 列序。

遍历不代表每个反应的所有部件均有完整断言；Godot 日志报错也不能仅凭遍历自动视为断言失败。运行测试需检查日志及退出结果，编译通过不代表测试执行通过。

主人已反馈当前游戏测试无问题，本轮未记录 TestDogSkinParts 实际运行通过的证据。视觉验收由主人或美术人员完成；后续视觉检查集中扩展到 DogSkinEditor，不由自动测试判断美感或所有穿帮问题。

编辑器维护边界见 [DogSkin 编辑器维护指南](../guide/dogskin-editor-guide.md)。
