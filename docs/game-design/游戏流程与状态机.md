# 游戏流程与状态机

## 游戏流程

```
WaitingForBet → 点 ChipStack → -5 筹码 → 发牌
Dealt → 点卡牌保留/弃牌 → Holding
Holding → 点狗给提示（一次性）→ 改保留牌 → 狗自动戴墨镜
Dealt/Holding → 点手臂（敲桌）/ DRAW 按钮 → 补牌动画
Drawing → 结算
  ├─ 赢了 → 出现奖励筹码 → 点筹码收集 → +payout → 自动发下一局
  └─ 没赢 → ChipStack 提示再点 → 回到 WaitingForBet
GameOver → 筹码归零 → 黑屏格言 → RESTART
```

## 状态机

`GameManager.State`:

| 状态 | 说明 |
|------|------|
| `WaitingForBet` | 等待玩家下注 |
| `Dealt` | 已发牌，等待选牌 |
| `Holding` | 玩家已选保留 |
| `Drawing` | 补牌中 |
| `Settled` | 结算中（赢了等收集筹码） |
| `GameOver` | 游戏结束 |

## ZIndex 层级

| 元素 | ZIndex | 说明 |
|------|--------|------|
| Background | 0 | 最底层 |
| 狗普通脸部 | 0 | Head/Eyes/Ears；在同层背景之后绘制 |
| 帽子 | 1 + Item.VisualZOffset | 0 保持历史遮挡，-1 移到固定眼镜和鼻子后面 |
| 固定眼镜/鼻子 | 1 | 同 Z 时按场景树顺序绘制 |
| 爪子手心 | 1 | 被桌子挡住 |
| 桌子 | 2 | Table |
| 舌头/爪子手背 | 3 | 挡住桌子 |
| 卡牌/筹码堆 | 4 | 在桌子上 |
| 手臂 | 5 | 最顶层 |

注意：爪子和舌头前景使用 `z_as_relative = false` 的绝对 ZIndex。`Item.VisualZOffset` 是所属装备位的本地偏移，目前只接入 Headwear；不得把它直接当作所有物品共享的全局层级。完整规则见 [小狗系统参考](./小狗系统参考.md)和 [Item 表字段说明](../numerical/Item表字段说明.md)。
