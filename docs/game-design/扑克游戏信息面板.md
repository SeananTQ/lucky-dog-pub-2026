# 扑克游戏信息面板

## 概述

游玩模式下，信息面板在扑克游戏面板左侧（或右侧，超出屏幕时切换），当前设计尺寸 246×600，实际显示随 UI 倍率缩放。

该面板仅存在于游玩模式。沉浸模式不显示信息面板（信息集成在 HUD 内）。

## 布局
```
┌──────────────────┐
│ 💰 :     88,888  │  ← 玩家持有筹码
├──────────────────┤
│ Royal Flush      │   100
│ Straight Flush   │    80
│ Four of a Kind   │    60 ← 当前段位，文字表现有变化
│ Full House       │    50
│ Flush            │    40
│ Straight         │    30
│ Three of a Kind  │    20
│ Two Pair         │    10
│ One Pair         │     5
│                  │  ↑ 牌型+奖励对照表
├──────────────────┤
│ 🎁  Bling Box    │
│     10000        │  ← 盲盒入口（预留）
├──────────────────┤
│ ⚙ Settings       │  ← 系统功能按钮
└──────────────────┘
```

## 功能

### 筹码与段位
- 显示当前筹码数，格式（`88,888`）
- 筹码显示完整数字，不使用 K／M 缩写或省略号。数字及分组符超过现有宽度时，在本面板内缩小字号；金额变短后恢复场景设定字号，不撑宽面板、不改变筹码栏高度，也不修改公共字体资源。
- 余额不足时仍显示“当前余额／下注额”；联机时显示牌局筹码，尚无余额时显示占位符。不同状态共用上述宽度适配，不改变筹码数值、数据上限或个人／牌局筹码的隔离。
- 2026-11-18 专项检查：修改前 `10,000,000` 会把面板从 246px 撑到 254px；修改后个人余额至 `int.MaxValue`、联机显示至 `long.MaxValue`、占位及切回个人余额均保持完整数字和固定尺寸。验证英美、法、德、印度数字分组格式及五档 UI 倍率；桌宠计数器的六档倍率和牌手面板当前网络数值上限（41,000）亦通过字体宽度检查。入口为 `--chips-display-main-smoke`，复用主场景内存 Mock 隔离，仅改变展示值，不写玩家筹码或账本。该检查是布局和字体度量验证，不替代人工视觉验收，也不表示扩大正式牌局筹码上限。

### 牌型奖励对照表
- 九种牌型 + 对应的奖励倍率（当前下注 × 倍率）
- 最低得分牌型为任意点数的一对，不要求 J 或以上
- 高亮玩家最近一次结算时的牌型行
- 点击赔率表打开扑克玩法帮助，再次点击可关闭。帮助覆盖扑克内容区域，不是独立 OS 窗口。
- 帮助包含「怎么凑牌」与「牌型一览」：前者自动演示换牌含义和保留策略，后者展示九种得分牌型及定时变化的合法示例。
- 首次主动展示时机尚未确定，当前仍由玩家点击赔率表进入。完整内容、输入边界、多语言与验收方法见[扑克玩法帮助说明](扑克玩法帮助说明.md)。

### 盲盒入口（预留）
- 按钮 + 消耗筹码数文字
- 当前版本：按钮不可点击，文字固定显示 `88888`
- 后续版本由盲盒系统驱动

### 系统功能按钮
- 点击后弹出系统功能面板（覆盖层形式）
- 默认定位在扑克游戏面板上方，复用 PanelPositioner 智能定位
