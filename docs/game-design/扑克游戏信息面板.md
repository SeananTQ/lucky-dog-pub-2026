# 扑克游戏信息面板

## 概述

游玩模式下，信息面板在扑克游戏面板左侧（或右侧，超出屏幕时切换），尺寸 240×600。

该面板仅存在于游玩模式。沉浸模式不显示信息面板（信息集成在 HUD 内）。

## 布局
```
┌──────────────────┐
│ 💰 :     88,888  │  ← 玩家持有筹码
├──────────────────┤
│ Royal Flush      │   100
│ Straight Flush   │    80
│ Four of a Kind   │    60 ← 当前段位，文字表现有变化
│ Full House       │    50
│ Flush            │    40
│ Straight         │    30
│ Three of a Kind  │    20
│ Two Pair         │    10
│ One Pair         │     5
│                  │  ↑ 牌型+奖励对照表
├──────────────────┤
│ 🎁  Bling Box    │
│     10000        │  ← 盲盒入口（预留）
├──────────────────┤
│ ⚙ Settings       │  ← 系统功能按钮
└──────────────────┘
```

## 功能

### 筹码与段位
- 显示当前筹码数，格式（`88,888`）

### 牌型奖励对照表
- 九种牌型 + 对应的奖励倍率（当前下注 × 倍率）
- 最低得分牌型为任意点数的一对，不要求 J 或以上
- 高亮玩家最近一次结算时的牌型行
- 点击赔率表打开扑克玩法帮助，再次点击可关闭。帮助覆盖扑克内容区域，不是独立 OS 窗口。
- 帮助包含「怎么凑牌」与「牌型一览」：前者自动演示换牌含义和保留策略，后者展示九种得分牌型及定时变化的合法示例。
- 首次主动展示时机尚未确定，当前仍由玩家点击赔率表进入。完整内容、输入边界、多语言与验收方法见[扑克玩法帮助说明](扑克玩法帮助说明.md)。

### 盲盒入口（预留）
- 按钮 + 消耗筹码数文字
- 当前版本：按钮不可点击，文字固定显示 `88888`
- 后续版本由盲盒系统驱动

### 系统功能按钮
- 点击后弹出系统功能面板（覆盖层形式）
- 默认定位在扑克游戏面板上方，复用 PanelPositioner 智能定位
