# 多游戏模式系统说明

## 全局约定

### 术语

| 术语 | 说明 |
|------|------|
| **宿主窗口** | 唯一的 OS 级窗口，无边框、透明背景、置顶。切换模式时重设尺寸 |
| **游戏面板** | 扑克内容的渲染区，600×600 或 1200×1200 |

### 模式切换规则

- 三种模式共用一个宿主窗口，切换时重设窗口尺寸
- 按老板键（快捷键）时立即切到伪装模式，再按切回之前的模式
- 伪装模式下的模式切换按钮：伪装 → 游玩

## 桌宠伪装模式（老板来了）

又称 Boss Key 模式。切换到此模式后，宿主窗口按玩家确认的桌宠倍率重新计算，看起来是一个停留在桌面或任务栏上的桌宠。

### 视觉布局

```
┌────────────────────────────┐
│ 💬 盲盒提示或倒计时          │   ← 可选气泡
│             🐕            │   ← 小狗
│ 🔄  12:30 /  88.8K    ⚙   │   ← 矩形面板
└────────────────────────────┘
```

- 小狗（含穿戴装扮）趴在面板中间，纹理直接用现有素材缩放
- 面板左右两侧两个图标按钮：切换模式（🔄）、系统功能（⚙）
- Counter 可显示时钟、筹码或 Steam 昵称，也可隐藏
- 气泡显示盲盒倒计时、可开启状态、筹码不足和 Loading 等玩家可见状态
- 小狗、Counter、普通盲盒提示、桌宠开盒表演和启动 Rise 动画使用同一桌宠倍率
- 系统功能面板保持固定尺寸，不随桌宠倍率缩放

### 技术实现

- 小狗场景保留 0.25 基础缩放，设置页提供 `0.5x / 1x / 2x / 3x / 4x` 五档相对倍率
- 桌宠 A 区以 265×235 为基础设计尺寸，胖窗口按缩放后的 A 区、固定面板缓冲和盲盒表演顶部范围计算
- `ContentA`、桌宠 CanvasLayer、Bubble 层和桌宠盲盒表演共享设计坐标，不使用 SubViewport
- 玩家应用新倍率后需在十秒内确认保留，否则恢复应用前的倍率和窗口位置
- 详细规则见[桌宠倍率与窗口布局说明](./桌宠倍率与窗口布局说明.md)

### 文字显示模式

| 模式 | 内容 | 示例 |
|------|------|------|
| 时钟 | 当前系统时间 | `22:30` |
| 筹码 | 当前筹码数 | `41544` |
| Steam 昵称 | 当前 Steam 玩家昵称 | `Player` |
| 隐藏 | 不显示 Counter | - |

## 桌宠游玩模式

标准游玩模式。宿主窗口尺寸为游客观看到的实际画面大小。

### 布局

```
┌────────────────────────────────────────────┐
│ ┌──────────────┐ ┌──────────────────────┐  │
│ │ 信息面板      │ │ 扑克游戏面板         │  │
│ │ 240×600      │ │ 600×600             │  │
│ │              │ │                     │  │
│ │ (筹码/牌型   │ │ (已实现 MVP 的      │  │
│ │  奖励/系统   │ │  扑克内容，50% 缩放) │  │
│ │  按钮)       │ │                     │  │
│ └──────────────┘ └──────────────────────┘  │
└────────────────────────────────────────────┘
     <- 840 ->
```

- 信息面板默认在左侧，屏幕空间不够时置右侧（复用 PanelPositioner 逻辑）
- 扑克游戏面板 = 现有 MVP 内容通过 SubViewportContainer 渲染到 600×600
- 信息面板详细内容见[扑克游戏信息面板](./扑克游戏信息面板.md)

## 沉浸游玩模式

全屏窗口模式，采用完整的 1200×1200 美术素材。

- 扑克游戏面板：直接使用现有 MVP 的 1200×1200 布局，不缩放
- 牌桌和背景：九宫格横向拉伸以适配宽屏显示器（`TextureRect.StretchMode.Tile` / `Scale`）
- 系统功能面板：以**覆盖层（Overlay）**形式弹出，不跳转页面
  - 覆盖层半透明遮罩，系统面板浮在中央
  - 关闭覆盖层后无缝回到游戏画面
  - 复用现有 Overlay CanvasLayer 结构
- 播放完整 BGM + SFX
- 可通过老板键随时快速切换到伪装模式
- 窗口尺寸默认为显示器分辨率，可在设置中改为窗口模式
