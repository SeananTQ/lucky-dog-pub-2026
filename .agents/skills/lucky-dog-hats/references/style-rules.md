# 美术规则 · 临时生产 v0.1

## 三档与简化顺序

- 第一档：厨师帽、早期礼帽、早期贝雷帽。
- 第二档：警帽、画家帽。与第一档肉眼差异可以很小，不机械增加附件区分。
- 第三档：主人指定的船长帽、麦克阿瑟军帽、戴珍珠耳环的少女头巾。主要依据名人、明星或知名经典造型关联；可以保留更多必要识别特征，但不必更复杂。未明确的关联不编造，不按游戏 ItemRarity 数字直接推导美术档位。

复杂度依次判断：档位及目标造型 → 材质能否辨识 → 删除冗余。删除某细节后帽型、指定造型及材质仍能辨识，就可以删。必要凸起、帽冠转折和主要折叠不能为简化被抹去。

## 共同画法与材质

所有档位均保持干净轮廓、较大的封闭色块、有限且协调的颜色，不使用围住整顶帽子的统一描边。高级不是加厚渲染或堆配件。

固定左上光源，只在材质和结构需要时保留高光或暗部。暗面可以表达画家帽、船长帽的凹陷及头巾必要褶皱；不全面禁止渐变或高光。能用纯色色面表达清楚时，不加无意义的明暗。

材质依靠软硬轮廓、厚度、翻折和少量概括线索体现。毛线帽不能变成光滑硬壳；也不需画密集针脚。硬质光面可有必要高光，不把同样亮斑套给所有材质。头巾要有必要交叠阴影，但不能遍布碎亮面、光滑丝绸式体积渲染及细碎珠宝切面。

硬边矢量般的分面也可能整体像厚涂；“封闭路径能描出来”不是通过理由。先看整体是否像项目里的帽子，再讨论细节能否修。

## 佩戴关系

近正面、已自然戴在项目狗头上的帽子；生成时省略狗头，不改变相机或把帽子掀起。本应被狗头、额头及前缘挡住的帽口和内部底面不可向观众敞开。

不一律禁止所有下表面：短鸭舌确实轻微上翘时，可少见帽檐下方。也不因为物理上解释得通就自动放行，应以项目佩戴关系判断。宽大不平整帽檐可以是识别特征，不能都拉成平直帽檐。

局部错误暗面若保留轮廓、分区与遮挡关系，只需换色就可用，属于可修候选；要改帽檐曲率、比例或主体遮挡则为结构重画。大范围整体画法偏离也不属于局部瑕疵。
