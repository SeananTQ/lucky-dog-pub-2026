# 小狗来啦帽子设计 · 临时生产 v0.1

交付可供主人 Illustrator 重绘的位图设计参考、实际生图提示词和视觉评审。允许约 10% 的局部修正；整体画风偏离、主体结构或佩戴角度需重画时不合格。本版收束已校准规则，尚未验证 90% 成功率；不要继续跑成功率实验，除非主人要求。

当前生产以现实中存在的帽型为主，允许保持帽型辨识的主题变化。纸袋、动物特征、顶物和表达玩家状态的特殊头饰留待主人明确启动，见美术规则中的“当前题材范围与后续方向”；不要因批量任务或节日主题自行扩展。

## 开始工作

从当前工作目录向上定位同时含 `lucky-dog-rise/` 与 `.agents/` 的项目根。项目外调用时定位主人指定的项目；不要猜另一个同名仓库。

读取 [美术规则](references/style-rules.md)、[视觉验收](references/visual-review.md) 和 [主提示词](prompts/hat-master.txt)。只有选参考或遇到专项帽型时再读 [参考与专项约束](references/reference-guide.md)。

将需求整理为 [任务卡](prompts/hat-brief.txt)，不要求主人逐项填表。已指定的档位、材质、人物关联和用途优先；能从项目或上下文确定的自行补齐，影响设计的未知项才简短询问。没有明确名人关联时标记待定，不编造，也不自动降档。

区分本次意图：新设计、同款变体、复刻原款、修改指定图。新设计应明确目标帽型及与参考的设计区别；复刻任务允许接近原图。不能为追求区别随意增添附件。

## 参考与提示词

临时生产优先挑选少量项目原始正例作为画风锚点，通常一张合适的大尺寸帽子即可；角度不稳定时加对应佩戴局部。这个默认策略是工作选择，尚无实验证明一定提高通过率。主人指定纯文字时照做，并记录无参考。

- 画风主参考来自 `lucky-dog-rise/Assets/v2/Headwear/`，不是 `ItemIcon/`。先查看真实图片，核实与目标相关。
- 现实帽子照片仅在识别结构确有需要时用，负责帽型与材料，不负责项目画风。不要为了普通新帽子必定寻找照片。
- 佩戴参考裁同帽子的单格，保留帽子、耳朵及必要头部上下文；不把整张几十顶帽子的拼图送给生图工具。不要复制狗、眼镜和背景。
- 每张输入图标明职责。新设计主要借用色块表达、简化尺度和佩戴关系，不能让“跟随参考”覆盖目标设计。
- 将任务卡填入主提示词，删去不用的行，保留一份最终逐字文本。不要把整段实验历史和每一种失败帽型都塞进去。

## 生图执行

使用可用的 `imagegen` 技能及内置生图工具。一顶帽子一次调用，完整呈现单顶帽子；纯浅色背景为默认，主人要求透明时使用真正透明背景。不要为了批量、路径或质量控制自行切到 CLI/API。

本项目若使用子 Agent，沿用主人指定的 `gpt-6.1-sol`、`high`，显式指定配置；不自动升级高级模型。该设置控制提示词和评审 Agent，不控制生图工具底层版本。若环境无法选择该配置，说明限制，不伪称已使用。单顶简单任务不强制拆 Agent。

使用当前工具实际支持的参考参数；本地参考先看图，再传路径。新图无参考时不填写参考参数。保存工具返回的原图到项目，不能只留在工具默认目录；保留所有本批调用的原图及失败记录。

项目输出默认放在 `assets/output/hat-production/YYYY-MM-DD/<批次名>/`，使用不覆盖已有文件的编号，例如 `H01-a01.png`、`H01-a01.prompt.txt`、`H01-a01.review.md`。记录参考路径、原图路径、任务意图、工具、子 Agent 配置（如有）、调用序号和本次结论。工具未暴露的模型或参数记为未知。

## 自检与返修

必须打开实际输出看图，按验收文件先判断整体画风，再看识别、结构与佩戴，最后判断局部修复量。不能因为提示词写了要求就认为输出遵守。批量结果可制作带编号的总览辅助比较，但逐图判断仍应能追溯原图。

默认先生成请求的每项一版。符合参考用途即可交付；局部可修须写出具体改色或删减位置，不必自动把主人可在 Illustrator 修掉的小问题无限重生。整体失败时，在已授权生成任务内可做一次针对性返修，并保留前一版；同帽型默认最多两次调用后展示剩余问题。主人明确指定的次数、预算或持续迭代要求优先。

改图只改变明确问题并保留已正确的结构；整体画风跑偏应重新收敛画法，不能用局部换色掩盖。返修后重新看图。局部编辑使用生图工具；不要用程序重绘帽子来伪装生成效果。参考裁切、等比展示排版和文件复制可确定性处理，不能改原始输出。

交付时展示结果，提供原图与最终提示词路径，区分“AI 初评”和“主人确认”，说明哪些需局部修正。近似复刻不代表新设计能力，重试选出的结果不代表首次成功率。未实际叠放到狗头或运行游戏时，不宣称已完成佩戴适配。

生成参考稿无需修改正式 Headwear、ItemIcon、Luban、PSD 或游戏代码；只有主人明确提出入库工作时再进入相应流程。
