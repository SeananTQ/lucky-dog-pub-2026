# 游戏公告

默认“游戏公告”指 Steam 社区公告；其他平台由用户特别说明。规则保留弹性，根据真实公告和用户反馈继续完善，不把单次选择升级为普遍硬规则。

## 工作流

1. 结合项目记忆、Git 记录和用户关注的功能点，先列候选改动。核对版本、渠道和比较范围，优先以上次公告版本到目标版本的差异为依据。记忆补充背景，当前 Git 和文件核实改动；范围不明时说明并询问，不重复把历史功能写成新增。提交和编译不等于运行体验验证。
2. 按下面原则筛选、合并、脱敏、口语化，形成中文初稿。审阅稿放在纯文本代码块中，用自然标题、空行、项目符号，不显示 BBCode。重要且不确定的取舍在块外简短说明。
3. 根据用户建议迭代。正文满意后才反推标题，遵循已批准的标题惯例；目前惯例格式尚未确定，需在实战中确定，不自行编造既有惯例。
4. 小型更新不需要副标题和概述。其他公告按需要提供副标题和突出重点、吸引阅读的概述。标题上限 80 字符，副标题 120，概述 180。每个语言单独检查；特殊字符计数必要时以 Steam 页面复核。
5. 最终复制稿放在带 BBCode 的 text 代码块中。标题在正文前，便于用户粘贴后剪切到标题栏；有副标题、概述时也放在正文前，标明字段。前置字段不属于正文首次出现游戏名的判断范围。检查落款链接，不遗漏反馈或适用的社交入口。
6. 中文满意后给英文和繁体中文。用户看过英文后，以英文稿为依据翻译其他所需语言。目前 Playtest 补日语；Demo 的语言清单由用户按实际玩家分布决定，不预设。
7. 留档到项目根目录 lucky-steamworks/announcements/，每次建立 YYYY-MM-DD-version-channel-topic 子目录，缺失信息省略，日期不代表发布承诺。保存 changes.md（比较范围及候选改动）、各语言审阅稿和最终复制稿，如 zh-CN-review.txt、zh-CN-steam-bbcode.txt、en-steam-bbcode.txt、zh-TW-steam-bbcode.txt、ja-steam-bbcode.txt。只创建实际完成的文件；修改已批准稿须明确说明，避免混淆。编辑授权不代表发布授权。

## 编辑原则

- 旧功能修改、优化：合并多次提交，写玩家最终感知的变化，省略内部修复过程。
- 新增功能：保留有意义的独立亮点，体现开发活跃度；可以包装、润色，不夸大效果、完成程度和验证范围。
- 通常筛掉盲盒内部逻辑、概率、加密、混淆、打包优化等细节。成就、云存档等玩家关心的内容保留实际用途和体验变化，简化内部实现。直接影响玩家权益或选择的变化需具体讨论如何说明，不自动隐藏影响。
- 正常、自然、稍偏口语，符合可爱游戏气质，避免法条感、机翻感、幼稚和过度卖萌。没有充分证据不写“完全”“始终”等保证。
- 大更新参考：开场感谢，版本说明，按桌宠、扑克、背包、奖励、同步等体验分类，测试重点及限制，反馈入口，结尾。栏目随内容选择，不必齐全。
- 小更新参考：一句话概括，“新增与调整”“优化与修复”，简短感谢和 Bug 链接。
- 用户确认的通用修改可完善 Skill，特殊取舍保留为案例。

## 名称和拟人化称呼

- 简体游戏名：小狗来啦；Demo：小狗来啦 试玩版。加粗，正文首次出现加书名号，例如 [b]《小狗来啦》[/b]。标题、副标题、概述不计入正文。后续书名号按自然阅读处理。
- 繁体游戏名：《Lucky Dog Rise：小狗來啦》；Demo：《Lucky Dog Rise：小狗來啦 試玩版》。加粗，保留完整混合名称。
- 英文及其他外语：Lucky Dog Rise；Demo：Lucky Dog Rise Demo。加粗、斜体，例如 [b][i]Lucky Dog Rise[/i][/b]，不翻译专名。
- 平台账号与公告语言无关：X 名称 Lucky Dog Rise，账号 @LuckyDogRise；小红书及其他中文社交媒体称 小狗来啦。不要翻译账号名或编造社交链接。
- “小狗”可作为品牌的拟人化称呼，类似“小招”“小度”，体现陪伴和成长，和正式游戏名分开。中文使用“小狗”的自然表达；英文优先尝试 Lucky Dog，不固定直译为 puppy。其他语言保留亲近感、允许改写，不硬造昵称。
- 日语区分品牌自称和团队称呼角色；この子（这孩子）更偏后者，不固定为品牌自称。具体句子里选择自然表达，不声称已确定日文昵称或未经验证的地区习惯。
- 用户只懂中文、略懂英文：外语拟人化称呼或语气取舍附中文回译和简短说明，让用户可判断亲近感及是否过于孩子气。

## BBCode 和链接

使用 [p]、[b]、[i]、[h2]、[list][*]…[/*][/list]、[url="…"]…[/url]。代码块用 text，不标成 CSS。翻译保留标签结构、专名和链接目标。

默认 Bug 反馈入口：https://steamcommunity.com/app/2583700/discussions/0/594062684485409967/

落款参考：感谢各位参与 Playtest。测试过程中遇到问题时，请参照 Steam 社区 Bug 反馈帖提供的模板，在 Steam 社区单独发帖反馈。将反馈文字或“Bug 反馈帖”设为链接；按渠道和用途调整，不必每次复述同一结尾。所有最终稿检查链接存在且目标未被翻译改写。

## 交付检查

核对版本、渠道、日期、比较范围和验证限制；审阅稿无 BBCode，复制稿有完整 BBCode；标题由正文提炼，所需字段字符数合规；各语言游戏名与平台账号正确；外语亲昵称呼附中文说明；落款链接完整；仅制作所需语言并留档。通过实际公告继续迭代规则。
