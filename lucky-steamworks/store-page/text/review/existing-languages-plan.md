## 原样备份的标准

1. 从当前 JSON 解码长描述为 `.bbcode.txt`，简介为 `.txt`，不从旧 Markdown 重新翻译。
2. 只解码一层 HTML 实体，并将 CRLF 换行规范为 LF，便于本地使用；不改动文字、标签顺序、引号、空段、其他空白或媒体引用。
3. 本地文件与上述解码结果逐字核对，不通过清理空白、统一口吻、补玩法或调整 Slogan 改动既有内容。
4. 对应旧 Markdown 保留原始字节归档。第一批已完成，详见[原文备份记录](existing-01-review.md)。
5. 纯备份不改变 JSON，不生成同内容的新上传文件，不需要为了本地归档重新上传。

## 补充末尾热词段的标准

1. 只研究上述 8 种语言的当地狗别称、狗名、梗及可能搜索词；核实实际名称，再创作自然段落。
2. 已有长描述作为固定前缀保留，只在正文媒体之后追加尾段，不重译前文。简介始终保持原值。
3. 地区变体只在新增尾段中分别处理当地用词、称呼和语法，不借此改写原有西语或葡语正文。
4. 审阅材料记录选词依据、采用或舍弃原因、实际覆盖及中文回译，不把说明混入商店正文。
5. 真正追加尾段后，才分别生成 Demo 与正式版的新完整累积 JSON；保留其余语言、各自页面身份和非文字字段。原始下载与已提交快照保持不变。
6. 上传、保存、发布仍由主人明确安排；本轮没有执行后台操作。
